# 🇰🇿 Патриотический Будильник Казахстан (Patriotic Alarm KZ)

Мобильное приложение под Android, созданное для истинных патриотов Казахстана. Будильник пробуждает под звуки Государственного Гимна Республики Казахстан, требует встать смирно перед фронтальной камерой с правой рукой на сердце, воспроизводит обращение Президента К.-Ж. Токаева под патриотическую музыку, фиксирует безупречную выправку и поддерживает 365-дневную серию пробуждений с развивающимися виджетами.

---

## 🌟 Основные возможности

1. **Реальный рабочий будильник с пробуждением экрана**:
   - `AlarmManager.setAlarmClock()` с наивысшим приоритетом.
   - Пробуждение устройства через `WAKE_LOCK` и `SHOW_WHEN_LOCKED`.
   - Запрос разрешений при старте: **Камера** (`CAMERA`), **Поверх других приложений** (`SYSTEM_ALERT_WINDOW`), **Уведомления** (`POST_NOTIFICATIONS`).

2. **Считывание позы в реальном времени (ML Kit Pose Detection)**:
   - Фронтальная камера (`CameraX`) отслеживает положение человека.
   - Контроль стойки: прямая спина, ровные плечи, отсутствие наклона.
   - Фиксация жеста: **правая рука прижата к сердцу** (слева на груди).
   - Расчет выправки:
     - **Смирность (Stillness score)**: процент неподвижности за время гимна (например, 98%).
     - **Скорость реакции (Acquisition time)**: секунды от включения будильника до принятия правильной стойки (например, 2.8 сек).

3. **Синхронизированное медиа-сопровождение**:
   - **Государственный Гимн Казахстана** звучит во время считывания позы.
   - Сразу после гимна запускается **видео с Президентом К.-Ж. Токаевым** (`ssstik.io_1794336684698~2.mp4`).
   - Синхронно с первых секунд видео играет патриотический трек (`you-cant-rush-perfection-slowed-zenyth-was-here_T4HyXjmR.mp3`).
   - По окончании видео открывается экран **«ВЫПОЛНЕНО! / ОРЫНДАЛДЫ!»** с подробной статистикой стойки и начислением +1 дня в серию.

4. **Патриотическая серия на 365 дней**:
   - **Правило времени**:
     - Будни (Пн-Пт): с **00:00 до 10:00**.
     - Выходные (Сб-Вс): с **00:00 до 12:00**.
     - Будильники позже указанного времени не засчитываются в серию (слишком поздно!).
   - **Заморозка серии**: разрешено пропустить **2 будильника в месяц** без сброса серии!
   - **37 рангов**: каждые 10 дней меняется ранг («Бастау» -> «Тұлпар» -> «Қыран» -> «Батыр» -> ... -> «Мәңгілік Ел»), дизайн и цветовая палитра виджета.

5. **Казахстанские виджеты для главного экрана Android**:
   - Настоящий `AppWidgetProvider` с динамическим обновлением.
   - Традиционный казахский орнамент («Қошқар мүйіз»), золотое солнце и парящий степной орел.
   - Отображение текущей серии, ранга, времени следующего будильника и запаса пропусков.

6. **Чистая векторная графика (SVG)**:
   - Все иконки в приложении — сгенерированные векторные SVG/XML ресурсы без использования дешевых смайликов.

## 📦 Готовый скомпилированный APK

Файл готов к установке:
- **[PatrioticAlarm-Kazakhstan.apk](PatrioticAlarm-Kazakhstan.apk)** (в корне репозитория)
- Размер: ~80 МБ (включает модели ML Kit, треки гимна, аудио и видео Токаева).

### Сборка из исходников:
```bash
./gradlew :app:assembleDebug
```
Файл соберется в `app/build/outputs/apk/debug/app-debug.apk`.
